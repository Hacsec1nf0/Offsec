# Offsec - AKAMAI WAF VALIDATOR

Open Source framework for validating Web Application Firewalls (WAF), API Gateway protections and Akamai security policies.

## Features

- API validation
- SQL Injection validation
- Cross Site Scripting validation
- Command Injection validation
- Path Traversal validation
- Oversized Payload validation
- HTTP Methods validation
- Rate Limit validation

## Supported

- Akamai
- Cloudflare (future)
- AWS WAF (future)
- Azure WAF (future)
- F5 ASM (future)

## Report

- Console Report
- HTML Report (coming soon)
- JSON Report (coming soon)
- Excel Report (coming soon)

## Installation

```bash
git clone https://github.com/Hacsec1nf0/Offsec.git

cd Offsec

pip install -r requirements.txt
```

Execute

```bash
python3 main.py
```
